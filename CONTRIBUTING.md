# Contributing

Small, verifiable improvements are welcome. Please keep the volume checker dependency-free and its arithmetic inspectable.

## Report a calculation issue

Include the shape, units, dimensions, depth, allowance, browser, actual result, and the calculation you expected. Distinguish display rounding from the value used to round whole bags upward. Use example measurements; do not post home addresses or personal information.

The [calculation issue form](https://github.com/lydiahub19921013/covercalcpro-landscape-quantity-kit/issues/new?template=calculation-issue.yml) lists the inputs needed to reproduce a result. Submitting an issue requires a GitHub account; using the checker does not.

## Correct a data row

Link the original public source, identify the exact field, and state the observation date. Do not infer missing density, price, package volume, or coverage. A historical product observation must stay dated rather than become a universal material fact.

## Submit a change

Explain the user task, keep the change focused, and run the examples in [TRY-IT.md](docs/TRY-IT.md). Check rectangle and circle results, metric input, invalid dimensions, and a narrow browser window. Do not submit copied proprietary material or add dependencies without discussing the need first.
