# Landscape quantity checklist

Use this short checklist before turning a measurement into an order or quote.

## 1. Capture the usable geometry

- Record the finished length and width for rectangles.
- Record the inside diameter for circles and round containers.
- Record the finished depth or container height.
- Split separate beds, strips, rings, or container specifications into separate rows.
- Keep one unit system per worksheet and write the unit beside every number.

## 2. Make the volume checkable

- Rectangle: `length × width × depth`.
- Circle: `π × (diameter ÷ 2)² × depth`.
- Convert depth to the same base unit before multiplying.
- Show measured volume before any waste, settling, or compaction allowance.
- Apply an allowance only when the project or supplier requires it, and label the percentage.

## 3. Match the product facts

- Copy the printed bag volume, not a remembered bag size.
- For pine straw, copy the supplier's actual coverage per bale.
- Copy density only when pounds or short tons are needed.
- Record supplier minimums or bulk order increments separately from geometry.
- Do not turn a planning starting point into a plant prescription or universal coverage claim.

## 4. Compare the purchase options

- Round bag quantities up to whole bags.
- Convert cubic feet to cubic yards with `÷ 27`.
- Enter bag, bulk, and delivery prices from the same quote or currency.
- Keep delivery or pickup visible as its own fee.
- Confirm the finished fill level, label, supplier minimum, and delivery rules before ordering.

## 5. Record the handoff

- Save the date, measured areas, units, product label, allowance, and quote source.
- Mark whether the number is measured, planned, or supplier-confirmed.
- If a value is unknown, leave it unknown instead of filling the gap with a generic average.
